# Éco-conception

Espace pour l'analyse des impacts environnementaux de Rustkins, les objectifs de sobriété, les mesures de ressources des pipelines et les recommandations d'utilisation.

Les engagements et chiffres éventuels ne seront documentés qu'une fois définis et étayés ; aucun objectif de performance environnementale n'est présumé acquis.

# Veille

Espace pour les synthèses suivies de veille : technologies CI/CD, sécurité, réglementation, alternatives de marché et évolutions des usages.

Distinguer la veille documentée (sources datées, effets possibles sur Rustkins) des comparaisons exploratoires et POC, qui restent dans `research/`. Une veille n'implique pas automatiquement une décision produit.

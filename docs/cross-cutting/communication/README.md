# Communication de Rustkins

Référentiel de la **stratégie de communication et du lancement de Rustkins**. Les fichiers Markdown ci-dessous constituent la source de vérité pour les messages, les médias, le plan d'actions et le script vidéo.

> **Statut :** propositions de communication en cours de validation (`draft`). Les échéances sont prévisionnelles ; les fonctions non livrées doivent être présentées comme prévues.

## Documents

| Document | Contenu |
| --- | --- |
| [Positionnement et messages](positioning-and-messages.md) | Punchline, publics cibles, **3 sujets** éditoriaux, propositions de valeur et règles de formulation |
| [Médias et communautés](channels-and-communities.md) | Les **4 médias dans l'ordre** : formats courts (YouTube Shorts, Instagram Reels, TikTok), Reddit, site vitrine, salons ; détail des **7 subreddits** et de leurs règles |
| [Plan de lancement](launch-plan.md) | Les **4 actions** de communication, responsables, temporalité, prérequis, objectifs et indicateurs |
| [Vidéo promotionnelle](promotional-video-script.md) | Format vertical, durée maximale de **2 minutes**, script et storyboard scène par scène |

3. **Quatre médias retenus par l'équipe** → [Médias, §1](channels-and-communities.md#1-les-quatre-médias-retenus-dans-lordre).
4. **Quatre premières actions et leur temporalité** → [Plan de lancement, §2](launch-plan.md#2-tableau-des-quatre-actions).
5. **Vidéo promotionnelle : format et script uniquement** → [Vidéo promotionnelle](promotional-video-script.md).

Un **PDF de synthèse** peut être généré à partir de ces documents Markdown. Les documents du dépôt restent la référence pour le contenu et ses mises à jour.

## Références et garde-fous

- [Roadmap produit](../../versions/roadmap.md) : source de vérité sur les fonctionnalités par version.
- [Modèle économique](../business-model/business-model.md) : ne pas présenter des prix ou offres encore indéfinis comme acquis.
- [Direction artistique](../art-direction/art-direction.md) et [charte graphique proposée](../art-direction/graphic-charter.md) : orientations visuelles, palette et principes UI ; documents au statut `draft`.

Toujours distinguer fonctionnalités **disponibles**, **en développement** et **prévues**. Ne pas promettre de conformité RGPD ou de sécurité automatique par l'auto-hébergement. Avant de publier sur Reddit ou d'annoncer une participation à un salon, vérifier les règles et les dates actualisées.

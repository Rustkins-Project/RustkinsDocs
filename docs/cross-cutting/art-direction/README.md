# Direction artistique de Rustkins

Ce dossier rassemble les orientations visuelles et les principes d'expérience de Rustkins.

## Documents

- [Direction artistique de Rustkins](art-direction.md) — identité de marque, valeurs, univers minimaliste, couleurs d'intention, thèmes clair/sombre et déclinaisons sur les supports.

**Périmètre :** la direction artistique est proposée au statut `draft`. Il ne s'agit **pas** d'une charte graphique finalisée : le logo, les typographies et les règles graphiques détaillées ne sont pas spécifiés ici.
